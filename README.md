# SoundSall

Baixe e edite músicas, e deixe a biblioteca inteira com o mesmo volume de uma vez.

**[⬇ Baixar para Windows](https://github.com/soundsall/soundsall/releases/latest/download/SoundSall-Setup.exe)**

Windows 10 e 11. Na primeira vez, o Windows pode mostrar um aviso de segurança: clique em "Mais informações" e depois em "Executar assim mesmo".
